# M17 — One-Run Scout Orchestration

## Goal
Give Scout one explicit owner-controlled run that executes every safe stage that does not require a new human trust decision.

## One-run flow
1. Reuse the existing green Scout core run for internship discovery, official resolution, immutable evidence, application preparation, company-domain enrichment and role contact research/classification.
2. Run the M13 ecosystem queries in the same request. These broad search leads remain ephemeral.
3. Automatically seed only curated official ecosystem recruiting targets already encoded in Scout's registry.
4. Research those official targets for explicitly published public business/recruiting contacts. New contacts remain `needs_review`.
5. Summarize M16 explicit application outcomes and user-chosen follow-up dates.
6. Surface accepted role contacts that are ready for a separate reviewed outreach-drafting decision.
7. Return one consolidated review queue.

## Human boundaries
M17 does not auto-promote portfolio-board leads, register unknown ecosystem pages, accept/reject contacts, create Gmail drafts, send email, submit applications, bypass CAPTCHA/login, or infer recruiter responses/follow-up dates.
