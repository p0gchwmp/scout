# Scout Sprout Capture

This unpacked Manifest V3 extension turns the visible Sprout opportunity into a one-click Scout handoff.

1. Start Scout locally with `npm run dev`.
2. Open the browser extensions page, enable developer mode, and load this directory unpacked.
3. While viewing a Sprout opportunity, click **Scout Sprout Capture**.

The extension reads only visible job metadata after the click and opens the owner-authenticated local Scout capture URL. It never transfers Sprout cookies, credentials, application answers, or unrelated account data. Scout independently searches/refetches official employer evidence and keeps submission and sending manual.
